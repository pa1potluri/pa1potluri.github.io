Privacy Policy

Last updated: 25 November 2026

PKP Stream Rotator

PKP Stream Rotator is a private tool used only by PKP Studio to manage its own YouTube channels. It changes the title and thumbnail of our own live streams at set times of the day.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to read and update the title and thumbnail of our own live broadcasts. It does not read viewers' data, comments, subscribers or any other person's information.

What it stores

The sign-in token is kept only on our own computer. Nothing is sold, shared or sent to anyone else. Access can be removed at any time from the Google account's security settings (Third-party apps & services).

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: use the contact details on the PKP Studio home page.
